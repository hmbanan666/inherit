# Kettlewick Works UI audit · 24 November 2026

Source-only review of the playable factory after PRs #102–#107.

## A. What to keep

- Keep the charcoal desk, gold actions, credit and level pills, and wide floor above Monaco. The Files tree, finder, gutter Run button and keyboard splitters feel like one IDE because they share the workshop palette. [Frame][frame] · [palette][palette] · [splitter][split] · [editor theme][theme]
- Keep the riveted tiles, enamel machines, depot crane, cart loads and printed villager portraits. The lathe has a copper cutter reel and the assembly table has an articulated arm. Keep all art, the contain-fit camera, silhouette picking and the pause mark on waiting carts. [Floor scene][floor] · [fabrication art][art] · [camera and picking][camera] · [portrait][portrait]
- Keep the quest card’s reserved goal space, tabular quantity and fixed action footer. Keep Tests beside the code, source links in Console, and the fixed-width CPU meter showing the recent high from worker CPU samples. [Quest card][card] · [Tests and Console][console] · [CPU meter][cpu]

## B. Where players lose the thread

| Area | What the player sees and why it matters |
| --- | --- |
| Onboarding | With enough ore in Bram’s hopper, the card says “Open the furnace and choose Smelt.” Doing that spends the ore but leaves the code-started batch check open. Later, even a hinge request ends with instructions to Collect from the furnace. [Next step][step] · [Bram’s checks][bram] · [delivery note][note] |
| Quest card and Tests | A resumed Harrow ingot contract can show plate and blank targets. The rail and Tests use today’s definition where the sim honors the saved order. On a fresh Harrow job the single-line ellipsis can hide the blank. [Card data][order-ui] · [saved check][saved] · [quantity style][quantity-css] |
| Machines | A gear sitting at the depot is invisible in its four-material inspector. At the assembly table, long recipes, shortages and “Set aside” rows end in an ellipsis. [Inspector data][inspect] · [inspector rows][facts] |
| Floor | With two carts, each sprite is drawn 12.5 world pixels off its cell’s horizontal center. Routes still start at cell centers and the route graphic is raised above machines on update. Following a waiting cart becomes harder. [Cart offsets][offset] · [route paint][route] |
| Editor | On a desktop-width window, saved Files and Tests widths can consume the editor bay. Zero space left is treated as unmeasured. Tests stays alongside Monaco and can squeeze the code and controls out entirely. [Layout predicates][layout] · [editor grid][grid] |
| HUD | The drone line can stay on “idle” throughout a mining run. Its two-tick hold needs two matching samples, but the watcher fires only when the computed words change. [Status binding][hud] · [two-tick hold][hold] |
| Console | At the 220px pane minimum, a fixed tick column and an unwrappable file path squeeze the message. Warnings and errors use the same color. The header also repeats the live tick in the footer. [Console rows][console] · [row styles][log-css] |
| CPU and Settings → Charts | The footer reports a four-tick high. Charts prints the latest sample as another CPU fraction and draws today’s ceiling across the entire history. Buying CPU +10 makes earlier samples appear to have had the higher limit. [Meter][cpu] · [chart series][charts] |
| Shop | Owned and unaffordable upgrades both dim the entire button to 45% opacity, including the explanation. It is hard to compare the next purchase. The same selector also dims reasons on machine actions. [Shop rows][shop] · [shared row style][facts] |
| API book | Repeat visits to Lathe start back at Furnace. Escape closes the book, but focus can reach the desk and global editor shortcuts can act behind the dialog. [Book][book] · [mount and unmount][book-mount] · [finder shortcuts][keys] |

## C. Ten edits, ranked by player impact

| Rank | Incremental change and visible result | Files touched | Size and risk |

| 1 | When the hopper is ready and Bram’s batch check is open, cue “Edit smeltOnce, then press ▶.” Use the quest’s own need text for ore and fabrication. Show the Collect hint only for furnace output. | Frame, questStep.ts, questNote.ts and their unit tests | M · medium. Check empty/full hoppers and an already-started batch. |
| 2 | Use the accepted order for quantity, hand-over text and footer, and the sim’s saved check for legacy Tests. Use definitions for previews. Drop the recipient prefix on split orders so both item counts fit. | Frame, questNote.ts, questStep.ts and their unit tests | M · medium. Cover old Harrow, current Harrow and the ordered crates. |
| 3 | List stocked depot parts via `itemNames` and `port(world, 'depot').get`. Wrap recipe, shortage and staged-part rows. Keep the drone task on one fixed line. | triggers.ts (inspector), Frame | M · low. Distinguish physical stock from reserved and delivered goods. [Stock reader][stock] |
| 4 | Center trucks horizontally on their occupied cells. Keep routes beneath equipment and hit-testing on the interpolated sprite. A waiting cart stays aligned with its lane. | floor.ts | S · low. Check the pick anchor between cells on a detour. |
| 5 | Distinguish an unmeasured bay from zero code room. Stack Tests first, then cap the displayed tree width so the active file and actions fit. Retain saved widths. | Frame, factoryLayout.ts and its unit tests | M · medium. Cover maximum saved widths just above the stacked mobile layout. |
| 6 | Feed the existing hold once per world tick. Both carts’ sustained tasks then reach the status line. | Frame, questStep.test.ts | S · low. Repeated snapshots of one tick must count once. |
| 7 | In a narrow Console, put the clickable source path below its message. Give warnings a gold marker and errors an alert marker. Keep event timestamps and give the footer sole ownership of the live tick readout. | Frame | S · low. Preserve source navigation and repeat counts. |
| 8 | Keep CPU and credits as historical traces. Remove their current-value captions. Label CPU “CPU per tick” and sample the limit with usage so the dashed ceiling steps up at purchase. | MetricsPanel.vue | S · low. Keep the historical trend accessible in text and the persistent meter authoritative. |
| 9 | Keep descriptions readable. Give affordable purchases a clear button edge, keep prices visible on unaffordable rows, and style Owned as quiet text. Scope to Shop’s existing purchase condition. | Frame | S · low. Verify all three states and leave the balance in the HUD. |
| 10 | Remember the last API section for the session. Move focus into the book, keep Tab inside it, suspend the underlying Deploy and finder shortcuts, and restore focus to the opener on close. | ApiBook.vue, Frame, CodeEditor.vue | M · medium. Cover opening from both the API button and Monaco. |
