# Inherit v8: quests at Kettlewick Works

Status: accepted 23 November 2026 ([ADR 0022](../adr/0022-quest-loop-no-loss.md), [ADR 0021](../adr/0021-v8-inherit-a-factory.md)).

The player inherits Uncle's workshop, Kettlewick Works, in a village. Villagers ask for things. The works do not play themselves.

## The loop

One villager, one quest, then the works wait. The player takes the quest. The card states the goal and why the current program is not enough. That why line is the hint: it may name a field, a brick, or a shop item, and it never shows the expression to paste.

Checks sit under the editor. They read the live world every tick. Delivery counts start at zero when the quest is taken, and a quest that needs a fresh baseline resets it then. The exact baselines are in the [first playable spec](../specs/v8-first-playable.md). They turn as the world runs. They never complete the quest and they never cost anything. When every check passes, **Complete quest** pays that quest's credits and XP. Shipping the goods does not pay. The next quest stays put until the player takes it, and only once the level is high enough.

Nothing repeats. After the last quest the card says more is coming.

Credits rise only from that button and fall only in the shop. They never go below zero. There is no rent, no bankruptcy, no deadline, and no pause. The clock keeps ticking, including while the tab is hidden. There is no speed button. The player's files, including `lib/`, are never replaced. **Start over** asks first, and it is the only reset.

Each quest's checks stay open under the program that cleared the previous quest. Later quests are easier if that code has been pulled into `lib/`.

## Shop

The shop is a button in the nav. A purchase applies at once and stays. Prices: Alloy 50, Hotter furnace 60 (a batch finishes in 2 ticks), Bigger cart 40 (capacity +2), Second drone 120, Prospect 40, CPU +10 for 80. Buying an item never turns a check green. Calling `furnace.alloy` or `prospect` before it is bought says that it is in the shop. Bought bricks show in the API panel with their one-line doc.

Every item is listed. Credits are the only gate. Level tiers for the shop are decided in ADR 0022 and are not in the code yet. The next villager is gated by level now.

Starting credits are 300.

## What is on screen

The charcoal frame, the villager portrait and speech, the file tree (`main.ts` and `lib/`), and settings for Console, API, Charts, and Start over. Deploy shows when the editor differs. Otherwise the nav says Running. The nav shows credits, credits per minute, level, and CPU used/limit.

The tick is 0.5 s. One drone starts at the depot. Vein A is ore and vein B is coal. Vein C is hidden until `prospect()`. The furnace turns 2 ore into 1 ingot in 4 ticks. The CPU limit starts at 30. Uncle's `main.ts` sets `const home = false`, so the cart fills at vein A and stays there.

## Later

ADR 0022 decides these, and the code does not have them yet. Do not fill the gap with a deadline, rent, or a wipe.

- Speed bonus: +25% XP for finishing within a par time shown on the card, with no penalty.
- Shop tiers by level, beside the villager unlocks that already exist.
- Audit: a chapter summary after the chain. No loss.
- Next inheritance: a new site. The player's `lib/`, credits, and XP carry over.
