# Inherit v8: quests at Kettlewick Works

Status: accepted 23 November 2026 ([ADR 0021](../adr/0021-v8-inherit-a-factory.md)). This page replaces the earlier loop (Mayor Hale, a working starter, pause, speeds, rent, bankruptcy, and a round that repeats).

## The loop

One villager, one quest, then the works wait. The card states the goal and why the current code is not enough. It does not give the line to paste. Tests sit under the editor and turn as the world runs. When every test is green, **Complete quest** pays credits and XP. The next quest stays put until the player takes it. Nothing repeats. After the last quest the card says more is coming.

Credits only rise from that button, and only fall when the player buys in the shop. They never go below zero. There is no rent, no bankruptcy, and no pause. The clock keeps ticking, including while the tab is hidden. The player's files are never replaced.

Each quest's tests fail under the code that cleared the previous quest. Later quests are easier if that code has been pulled into `lib/`.

Hints name the idea (a full cart, coal, a second drone, an empty vein, the order's item, a remembered path). They do not name the expression.

## Shop

The shop is a button in the nav. A purchase applies at once and stays. Prices: Alloy 50, Hotter furnace 60 (batches finish in 2 ticks), Bigger cart 40 (capacity +2), Second drone 120, Prospect 40, CPU +10 for 80. Bought bricks show in the API panel with their one-line doc. Calling a brick before it is bought explains that it is in the shop.

Starting credits are 300, so Alloy and the second drone can be bought before they are needed. Buying them does not pass a quest. The tests still want the new behaviour in the code.

## What stays

The charcoal frame, the village portraits, the file tree (`main.ts` and `lib/`), settings for Console, API, Charts, and Start over, Deploy when the editor differs, and a large credit balance. The tick is 0.5 s. One drone, vein A (ore) and vein B (coal) at the start. Vein C is hidden until Prospect.
