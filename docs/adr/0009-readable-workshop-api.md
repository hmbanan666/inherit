# Syntax colors and a readable workshop API

The Code workshop uses an explicit Monaco theme on near-black charcoal with a warm amber accent. Keywords, strings, types, comments, numbers and functions have distinct colors, with hex fallbacks to keep code readable when a palette variable is missing or invalid. Players browse API calls by purpose as the chapter introduces them. Each card pairs a signature with a one-line description and a short example. The same entries generate api.d.ts for types and autocomplete, keeping raw declarations out of the workshop tabs.
