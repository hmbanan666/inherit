# Soft pressure, no game over

> Superseded by ADR 0008, then by [ADR 0021](0021-v8-inherit-a-factory.md). [ADR 0022](0022-quest-loop-no-loss.md) is the no-loss rule and does not restore deadlines, debt, or reduced late pay.

Deadlines and debt create urgency, but failing is cheap: late work pays less, moods drop, an order may be withdrawn, a missed installment adds interest. Nothing resets progress or ends the game. The game is for keeping TypeScript sharp without stress.
