# The town gives every task its meaning

Players reached "ship 3 iron ingots" and asked why. We replaced the 75-item objective list with requests from named townspeople who have a reason and a deadline, and every fulfilled request visibly changes the town. Technical goals still exist, but only as something a person needs. A short onboarding wrapped in the first request is the only step-by-step part.

Considered: a pure sandbox (no direction for beginners), objectives with better text (still a checklist).
