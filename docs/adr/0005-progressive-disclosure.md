# Show tools only when the story needs them

> Superseded by [ADR 0022](0022-quest-loop-no-loss.md). Credits, level and the CPU meter are visible from the first tick. Console, API and Charts stay in the menu.

The v2 screen showed CPU, research, tests, metrics, drivers, snapshots and a second site from minute one, and beginners did not know what mattered. In v3 the engine keeps these features, but the UI shows each one only after a request introduces it. The CPU meter stays hidden in chapter 1 and returns mid-game as a paid controller upgrade. Unlocks come from the story (a townsperson gives or sells you the thing), not from a research tree.
