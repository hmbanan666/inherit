# Inherit

Inherit lets players discover how familiar software works by rebuilding a mechanism from an open-source project.

## Language

**Chapter**  
A connected sequence of challenges authored by an agent around one mechanism in a particular revision of a source project. The player carries their implementation from one challenge to the next.

**Challenge**  
A playable situation in a chapter that asks the player to reproduce an observable behavior. Any implementation that satisfies the required behavior earns progression.

**Experiment**  
A sequence of actions the player can try on both the original and their own implementation to compare what happens.
